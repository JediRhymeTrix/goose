# Talk overview: From Goose to the GDK

Format: ~8 short slides, followed by a live demo or prerecorded video
Subject: How the open-source Goose agent is being unbundled into the Goose Development Kit (GDK): reusable lower-level components for building agent-powered products
Topics covered:
  - A brief introduction to Goose as a general-purpose agent, founding project of AAIF
  - Why the ecosystem needs reusable agent infrastructure in addition to complete coding-agent applications
  - The GDK’s composable Rust crates for providers, agent capabilities, local inference, context management, compaction, and related infrastructure
  - Cross-language access through UniFFI, and ACP
  - Goose’s continuing role as a reference client and ACP server
- Demo/video: A short CLI application built from Goose components that uses the agent loop and local inference
